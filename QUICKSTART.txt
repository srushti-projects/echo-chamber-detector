🚀 HOW TO RUN:

STEP 1: Initial Setup (Run Once)
──────────────────────────────────
1. Open PowerShell or Command Prompt
2. Navigate to: C:\Users\rushali\Downloads\Internet Echo Chamber Detector\new-repo
3. Run: setup.bat

This will automatically:
- Train ML models (generate model.pkl and vectorizer.pkl)
- Install backend dependencies
- Install frontend dependencies (npm install)

STEP 2: Train ML Models
─────────────────────────
In the new-repo folder, run:
  cd ml
  python train_vectorizer.py
  python train_model.py

You should see:
  ✅ vectorizer.pkl created
  ✅ model.pkl created

STEP 3: Start Backend Server
──────────────────────────────
In new-repo folder, open a terminal and run:
  start-backend.bat

OR manually:
  cd backend
  python -m uvicorn main:app --reload --host 0.0.0.0 --port 8000

Expected output:
  Uvicorn running on http://0.0.0.0:8000
  Press CTRL+C to quit

STEP 4: Start Frontend Server
──────────────────────────────
In new-repo folder, open ANOTHER terminal and run:
  start-frontend.bat

OR manually:
  cd frontend
  npm run dev

Expected output:
  VITE v5.0.0 ready in X ms
  ➜ Local: http://localhost:5173/

STEP 5: Open the Website
────────────────────────
Open your browser and go to: http://localhost:5173

📊 HOW TO USE:

1. You'll see the Echo Chamber Detector interface
2. Enter social media posts in the text area
3. Click "+ Add Post" to add multiple posts
   (Or press Ctrl+Enter as a shortcut)
4. Click "📊 Analyze Posts" button
5. View results:
   - Left-leaning percentage (🔴)
   - Neutral percentage (⚪)
   - Right-leaning percentage (🔵)
   - Echo Chamber Score (higher = more polarized)

🔗 API ENDPOINTS:

POST /analyze
─────────────
Analyzes posts for political bias

Request:
  curl -X POST "http://localhost:8000/analyze" \
    -H "Content-Type: application/json" \
    -d '{"posts": ["Climate change is critical"]}'

Response:
  {
    "left": 100.0,
    "right": 0.0,
    "neutral": 0.0,
    "echo_score": 100.0
  }

GET /health
───────────
  curl http://localhost:8000/health

Returns server and model status

🔧 TROUBLESHOOTING:

Problem: "Model not found" error
─────────────────────────────────
Solution:
  1. Make sure you ran: python ml/train_model.py
  2. Check that model.pkl and vectorizer.pkl exist in ml/ folder
  3. Restart the backend server after training

Problem: "Cannot connect to localhost:5173"
──────────────────────────────────────────────
Solution:
  1. Make sure frontend is running: check npm run dev output
  2. Port 5173 might be in use - close other apps using it
  3. Try a different terminal/shell

Problem: npm install fails
──────────────────────────
Solution:
  1. Make sure Node.js is installed: node --version
  2. If not: Download from https://nodejs.org/
  3. Restart terminal after installing Node.js
  4. Try again: npm install in frontend folder

Problem: CORS error in browser console
──────────────────────────────────────
Solution:
  1. Backend CORS is already configured
  2. Make sure backend is running on http://localhost:8000
  3. Check browser console for exact error
  4. Backend now supports both port 5173 and 3000
